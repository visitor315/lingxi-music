# 灵犀音乐 (LingXi Music) 前端架构与极速开发修改指引

本文档面向所有参与维护本项目的开发者与 AI 助手，旨在提供清晰、高效的代码结构导航、数据流转机制与极速开发规范。

---

## 一、架构设计哲学与产物同步

本项目前端采用**源码模块化解耦 + 原生极速组装**架构：
1. **源码单一可信源**：全部业务、样式与结构源码严格维护在 `src/` 目录下。
2. **零依赖极速组装**：通过原生 Python 脚本 `scripts/build.py`（耗时约 10ms，零 npm / Node 依赖），将源码按严格依赖序合并生成三端目标产物：
   - `index.html`（根目录主 Web 入口）
   - `音乐.html`（根目录独立纯网页版入口，电脑端双击即可聆听）
   - `android/app/src/main/assets/index.html`（Android App 真实打包资源）
3. **视觉美学规范**：全站坚守古典文人水墨宣纸美学（宣纸底色、温润墨色、极细墨线、留白），严禁使用浮夸高饱和度色彩、半透明橙色或橙色描边。

## 三、核心数据流与生命周期

### 1. 播放链路 (Audio Lifecycle)
```text
用户点击歌曲 / 发现推荐流
         │
         ▼
playTrack(index, playlist) ──► 切换全局 currentPlaylist / currentTrackIndex
         │
         ├───────────────────► 更新 HTML Audio 标签 src 并调用 .play()
         │
         ├───────────────────► 加载并解析歌词：loadLyric(track) ──► parsedLyrics
         │
         ├───────────────────► 触发 updatePlayerUI()：更新底栏与全屏页唱片/歌名/作者
         │
         └───────────────────► 通知 Android 宿主：updateLockscreenMedia() (MediaPlaybackService)
```

### 2. 歌词渲染与跟随链路 (Lyric Sync)
- `audio.ontimeupdate` 触发 `updateLyricProgress(currentTime)`。
- 在 `parsedLyrics` 中使用二分查找定位当前时间对应的高亮行索引。
- 若用户未在手动触摸拖动歌词，调用 `scrollLyricTo(index)` 平滑居中滚动。

### 3. 系统返回键拦截优先级 (Back Key Hierarchy)
`handleSystemBack()` 函数是系统返回键的唯一入口，按严格降序逐层收起：
1. 活动弹窗与底部抽屉（操作菜单、确认弹窗、接口设置弹窗等）。
2. 全屏播放详情页（收起并平滑回到主页）。
3. 主题与外观个性化子页。
4. 全屏搜索页。
5. 歌单详情页 / 歌单编辑页。
6. 主界面：调用 `window.AndroidBridge.minimizeApp()` 退回手机桌面。

## 四、极速开发工作流（AI 与开发者统一遵循）

所有代码修改必须严格遵循以下三步闭环：

### 步骤一：定位并修改源码
1. 查阅第二节表格，找到对应的一个或多个子模块文件（位于 `src/css/`、`src/js/` 或 `src/template.html`）。
2. **严禁直接修改根目录或 assets 下的 index.html / 音乐.html**。
3. 针对子模块文件进行小颗粒度编辑。各子模块体量小（100-900 行），不会发生上下文丢失或行号漂移。

### 步骤二：执行极速编译与校验
在命令行执行：
```bash
python scripts/build.py --check
```
- 该命令将在 ~10ms 内自动组装模块，覆盖三个目标文件。
- `--check` 参数会自动进行 JavaScript 语法 AST 校验，若存在语法错误会立即报错并阻止推进。

### 步骤三：验证与测试
- **电脑端快速验证**：双击根目录下的 `音乐.html`，在浏览器中查看效果。
- **真机无线调试验证**：
  若需在 Vivo / iQOO Neo9 手机验证，执行：
  ```bash
  python scripts/check_build.py
  ```
  该脚本会自动轮询云端构建，下载 APK 并通过 ADB 无线推送到手机安装启动。

## 五、项目开发铁律（严格不可违反）

1. **绝对禁止使用任何 Emoji**：代码、注释、提交信息及文档回复中，严禁出现任何 Emoji 表情。
2. **绝对禁止使用·符号（间隔号 U+00B7）**：连接处或作者分隔一律使用半角减号 - 或空格替代。
3. **视觉风格铁律**：水墨宣纸素雅古典美学，严禁使用半透明橙色、高饱和度或现代霓虹风格控件。
4. **真机保护禁忌**：严禁通过 adb 执行 `input tap` 等模拟屏幕自动点击脚本。
5. **版本号升级纪律**：未经用户明确要求发布新版本，严禁随意递增 `version.json` 中的 `versionCode`，避免触发家庭端应用强制更新。
